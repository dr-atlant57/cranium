Configuration — CRANIO

La configuration décrit l’état d’un système à travers les relations entre ses éléments.

Why configuration matters

A system is not defined only by its individual parts. Configuration describes how those parts relate, align, distribute load and change together.

From experience to configuration

Experience gives the human entry point. Observation makes the state visible. Configuration gives the system a precise way to describe what is happening without prematurely assigning a cause.

01 / SCAN

Подключить и измерить

Подключите Vita Scan и три пары контактов. После проверки подключения начните Vita-тест.

SCAN — подключение и тестирование. CREATE — обработка и автокомплекс. TAP — передача NFC. START — подтверждение и запуск на приборе.

03 / System architecture

Три компонента. Три функции.

01 / INPUT

VITA SCAN

Компактный измерительный модуль USB-C. Три пары контактов: голова, запястья, голеностопы.

02 / INTELLIGENCE

VITA APP

Vita-тест, обработка, генерация автокомплекса и история сеансов.

03 / EXECUTION

VITA BALANCE

Персональный прибор для получения и выполнения автокомплекса.

Одно касание вместо сопряжения. NFC — приоритетный способ передачи готового автокомплекса. Bluetooth может оставаться дополнительной возможностью.

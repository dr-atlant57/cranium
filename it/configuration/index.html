Configurazione

La configurazione descrive lo stato di un sistema attraverso le relazioni tra le sue parti.

Ciò che osserviamo

CRANIUM parte dall'esperienza, dal contesto e dallo stato. La configurazione emerge dalle relazioni tra le parti e da come cambiano nel tempo.

Il principio CRANIUM

Esperienza → Contesto → Stato → Osservazione → Storia → Pattern → Stato successivo.

Metodo

OSSERVARE → CALIBRARE → IDENTIFICARE → OTTIMIZZARE → VERIFICARE.

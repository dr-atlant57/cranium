CRANIO / Primordocciput
The Primary Cranial Reference

Primordocciput

A CRANIO concept for understanding the skull base and upper-neck relationship as a primary reference for observation.

The model

CRANIO begins by asking where the head is referenced and how the upper support system accommodates that configuration.

Primary versus compensation

The model distinguishes the reference configuration from changes that may appear elsewhere as the system adapts. This organizes observation without assuming every downstream pattern has the same origin.

Research layer

Definitions, diagrams, observations, measurements, interpretations and open questions should remain distinguishable. The goal is an inspectable model.

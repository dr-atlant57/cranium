CRANIO · Configuração

Configuração

A configuração descreve o estado de um sistema através das relações entre as suas partes.

O que observamos

CRANIO começa pela experiência, pelo contexto e pelo estado. A configuração emerge das relações entre as partes e de como elas mudam ao longo do tempo.

O princípio CRANIO

Experiência → Contexto → Estado → Observação → História → Padrão → Próximo estado.

Método

OBSERVAR → CALIBRAR → IDENTIFICAR → OTIMIZAR → VERIFICAR.
